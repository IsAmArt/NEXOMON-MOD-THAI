# Nexomon Thai Mod — v1.0.0-rc1

Unofficial Thai localization for the first Nexomon on PC/Steam, covering the **main story and late-game additional content**, dialogue, menus, items and descriptions. Includes TA Regular/Bold fonts designed by TA Font (IsAmArt), 713 reviewed runtime text assets and 139 Thai skill descriptions. Nexomon and skill names retain their original English names.

The developer has completed the **main story and late-game additional content** using the Thai mod, with no system issue blocking story progression in that playthrough. The RC was also installed and launched successfully on a second notebook.

**RC NOTEBOOK INSTALL / LAUNCH = USER-CONFIRMED PASS**

This confirms installation/launch and the paths played, not exhaustive regression coverage. Not all late-game Legendary Nexomon have been caught, and every subsequent case has not been checked. Any further story content after those activities remains unconfirmed.

Some sentences may still need contextual polishing, and word wrapping or line breaks may be awkward in places. Development is done in spare time; further refinements are intended for a later version when time permits, without an update date being promised.

The Release DLL has no EXP multiplier. Existing levels earned during previous QA testing are not reset. Typography and font roles remain unchanged. See [Known Issues](KNOWN_ISSUES.md): Warden font is visually confirmed; Volleyball and Expansion popup retests remain pending.

Requirements: Windows x64, your own Nexomon PC/Steam copy (developer-tested build 5270054 / Unity 2019.2.8f1), and BepInEx 5.4.23.5 x64 installed separately. Unity Editor is not required. Follow [Installation](INSTALLATION.md) and [Typography Guide](THAI_CONFIG_GUIDE.md). Select THAI at startup; close/reopen to switch to ENGLISH. Uninstall only this plugin directory; retain shared BepInEx and saves.
